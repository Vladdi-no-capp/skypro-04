# English Cards

Учебное React-приложение для работы с карточками английских слов. Проект демонстрирует клиентский роутинг, защищённые страницы и простую авторизацию через состояние React.

## Запуск

```bash
npm install
npm run dev
```

## Проверка

```bash
npm test
npm run build
```

## Маршруты

- `/` — каталог карточек;
- `/login` — вход;
- `/register` — регистрация;
- `/new-card` — добавление карточки;
- `/card/:id` — просмотр и редактирование карточки;
- `/exit` — подтверждение выхода;
- `*` — страница 404.

Рабочие страницы защищены: неавторизованный пользователь перенаправляется на `/login`.
